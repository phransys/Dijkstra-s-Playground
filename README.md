Dijkstra's Playground

A dungeon style puzzle game built with Pygame where players navigate graphs using Dijkstra's Algorithm.

Features 
- Graph traversal
- Weighted edges
- Scores based on optimal path

Instructions:
- Click on node to traverse
- Click on previous to backtrack

```bash
pip install pygame
pip install main.py
```
